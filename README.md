# NDotShell

**Un escritorio Nothing OS para Hyprland** — teléfono holograma 2.5D,
Dynamic Island, drawers laterales y canales de acento.

[![Release](https://img.shields.io/badge/RELEASE-1.2.0-D71921?style=flat-square&labelColor=0B0B0B)](https://github.com/OptiJK181/NdotShell/releases/latest)
[![Linux](https://img.shields.io/badge/ARCH%20LINUX-1793D1?style=flat-square&labelColor=0B0B0B)](https://archlinux.org)
[![Hyprland](https://img.shields.io/badge/HYPRLAND-00FFD5?style=flat-square&labelColor=0B0B0B)](https://hyprland.org)
[![License GPL-3.0](https://img.shields.io/badge/GPL--3.0-F5F5F5?style=flat-square&labelColor=0B0B0B)](https://github.com/OptiJK181/NdotShell/blob/main/LICENSE)

```fish
# instalar en una línea
bash (curl -fsSL https://raw.githubusercontent.com/OptiJK181/NdotShell/main/get.sh | psub) --yes
```
