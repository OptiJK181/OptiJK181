# NDotShell

**Un escritorio Nothing OS para Hyprland** — teléfono holograma 2.5D,
Dynamic Island con agujero negro girando, drawers laterales gelatinosos,
Pomodoro con stats persistentes, clipboard privado y wallpaper dinámico.

<br/>

<a href="https://github.com/OptiJK181/NdotShell/releases/latest">

</a>

</a>
